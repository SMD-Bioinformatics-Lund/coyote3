Clinical contracts, rules, application operations and report inputs for trusted Python hosts. The core accepts explicit authorization, storage and integration capabilities; it does not start an API, connect to MongoDB or read deployment secrets.

## Package identity

The distribution is `coyote-core`; the Python namespace is `coyote`.
Its version, dependencies and build configuration belong to
[pyproject.toml](pyproject.toml). See [CHANGELOG.md](CHANGELOG.md) for changes.

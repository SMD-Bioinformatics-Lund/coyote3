## Deployment Responsibilities

The application license permits free institutional and commercial operation and
supported configuration. Protected implementation changes and redistribution
require the written permissions specified in the license. It is source-available,
not an open-source license. It does not validate a deployment for clinical use. Each
deploying organization remains responsible for local assay validation,
clinical governance, privacy and security controls, regulatory obligations,
and qualified review of clinical results.

Keep third-party dependency licenses compliant in packaged releases.

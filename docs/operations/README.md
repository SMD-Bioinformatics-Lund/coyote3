Use these guides to check a running installation, investigate failures and maintain
its data. For a new deployment or upgrade, start with [Installation](../deployment/README.md).

## Choose a task

| Task | Guide |
| --- | --- |
| Investigate a service failure | [Troubleshooting](troubleshooting.md) |
| Trace a request or user action | [Audit events and logs](audit-and-logging.md) |
| Check service and data health | [Maintenance checks](maintenance-and-verification.md) |
| Configure monitoring | [Monitoring and alerts](monitoring-and-alerts.md) |
| Investigate a delayed or failed ingest | [Ingest job recovery](ingest-job-recovery.md) |
| Investigate worker queues or background delivery | [Background delivery](background-delivery.md) |
| Configure or troubleshoot messages | [Email and notifications](email-and-notifications.md) |
| Back up or restore data | [Backup and recovery](backup-and-recovery.md) |
| Enable Redis transport encryption | [Redis TLS](redis-tls.md) |
| Update reference data | [Atlas reference updates](knowledgebase-updates.md) |
| Convert existing data | [Migration procedures](migrations/README.md) |

If the application works but a sample or result is missing, start with
[sample readiness](../user-guide/sample-readiness-and-missing-results.md).
Account and assay changes belong in [Administration](../administration/README.md).

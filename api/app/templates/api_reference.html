API scope

The API serves the Coyote3 interface and integrations with laboratory pipelines. It provides sample ingestion, finding review, reference evidence, classification and reporting operations.

Administration endpoints manage assays, assay configurations, gene lists, reporting rules and the public catalog. The same permissions and assay, environment and sample-access restrictions apply to API clients and the application.

Authentication and access

Browser: sign in to Coyote3. The explorer uses your session cookie and retrieves the CSRF token required for changes.

Scripts and integrations: send an opaque session token as Authorization: Bearer <session-token>. Bearer-authenticated requests do not require a CSRF header.

Public endpoints and pipeline ingestion tokens have operation-specific access requirements. Check the selected endpoint before sending a request.

Requests and support

Use this installation's URL prefix and the endpoint's documented parameters. Review validation details for rejected requests; do not retry a timed-out write without checking its outcome.

Include the response's X-Request-ID when reporting a failure. Keep patient data, credentials and session tokens out of support tickets and shared examples.

Browser session settings

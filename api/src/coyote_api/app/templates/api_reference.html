Authentication

Browser: sign in to Coyote4 on this host. The explorer uses your session cookie and retrieves X-CSRF-Token for changes.

Scripts: send your session token as Authorization: Bearer <token>. In the explorer, paste the raw token into Authorize → BearerAuth. Bearer requests do not need CSRF.

Your first request

Read GET /auth/providers, then log in with POST /auth/sessions using username, password and provider. The session token is in the Set-Cookie header.

curl --fail-with-body \
  "https://YOUR_HOST{{ prefix }}/api/v1/auth/whoami" \
  -H "Authorization: Bearer $COYOTE4_SESSION_TOKEN"

Replace YOUR_HOST with your installation's host. Authentication guide

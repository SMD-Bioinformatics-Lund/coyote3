# HTTP client changelog

## 1.0.0

- Use the language-specific distribution name `coyote-pyclient` and import namespace
  `coyote_pyclient`, independently of the Coyote application generation.
- Separate fast preview-transport smoke checks from the broader sync/async unit
  suite and measure the complete client namespace with its own branch-coverage gate.
- Include Ram Nanduri's copyright and SMD affiliation, with Viktor Henmyr and
  Sailendra Pradhananga credited as contributors, in standalone distributions.
- Provide synchronous and asynchronous HTTP-only clients with independent models.
- Participate in editable uv workspace development without a core dependency.
